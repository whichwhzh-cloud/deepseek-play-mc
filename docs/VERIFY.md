# 游戏内验收

用已有世界的备份或新测试世界，启动后确认载入的是 0.6.1-preview。普通皮肤版先关闭双方的 YSM 模型。

| 场景 | 观察结果 |
| --- | --- |
| 浅水横渡和上岸 | 选可浮起的浅水点和有明显落脚面的一侧岸边。观察伙伴是否跟随路线朝向、上岸以及是否耗尽氧气 |
| 草地错层 | 从两个斜向起点分别试一次一级草地台阶，观察是否优先绕到正向、是否反复卡在同一格 |
| 牵手走过楼梯与浅水 | 持续牵手，取消后能响应普通移动和发言。此项与自主寻路分开观察 |
| 双人菜单 | 右键开菜单，坐下后再次右键选依靠、两个膝枕、梳头。Shift 清除姿势 |
| 背负、梳头、雨伞、睡眠 | 验证挂载和下背、持刷右键、露天与屋檐切换、上床与起床 |
| 游戏和 AI 事件 | 检查主动邀请能接受；在伙伴枕膝时摸头，伙伴能收到摸头反馈 |
| 清理与回滚 | 退出重进后无遗留动作；在游戏关闭时回滚，旧 JAR 与旧文件恢复 |

0.6.1 的编译、安装回滚、模组注入目标签名和资源检查可离线完成。水边、草地及普通皮肤动作需用以上步骤实测。遇到超时请记下伙伴当时的位置、目标高度和任务类型。`numen.inv.eat` 属于独立身体任务，不能用它验证本版寻路改动。
